# 账号分析 / 运营

分析B站账号：自己的账号概况、消费习惯画像，或对标某个UP主做内容研究。

> **拉取视频详情/评论等资源时看 `downloading.md`。**
> 涉及"我"的数据（history、favorites、my-dynamics）需登录（`bili status` 检查）。
> `bili` 命令始终加 `--yaml`，用 `--max` 控制返回量。
> 命令集已在 bilibili-cli 0.6.2 源码中逐一核验（2026-09）。

## 场景路由

| 用户说 | 走 |
|---|---|
| "我的账号怎么样" | 账号概况 |
| "我最近都在看什么"、"分析下我的口味" | 消费画像 |
| "分析下XX UP主"、"对标一下XX" | 对标分析 |
| "我发的动态/数据" | 自有内容 |

## 账号概况

```bash
bili whoami --yaml        # 等级、硬币、粉丝数、关注数
bili status --yaml        # 登录状态
```

## 消费画像（需登录）

数据源：

```bash
bili history --yaml          # 观看历史
bili watch-later --yaml      # 稍后再看
bili favorites --yaml        # 收藏夹列表（逐个 bili favorites <ID> --yaml 深入）
bili following --yaml        # 关注列表
```

分析流程：
1. 拉齐数据源（并行）
2. 归类：看的视频按主题/UP主聚类，收藏 vs 看过 vs 稍后再看的差异
3. 输出画像：兴趣分布（哪类内容占比高）、活跃度（历史条数/最近频率）、关注结构（关注了多少UP主、类型）
4. 给 1-2 条可执行的观察（如"收藏了很多教程但稍后再看堆了 30 条"），不要泛泛而谈

## 自有内容

```bash
bili my-dynamics --yaml                      # 我发的动态
bili user-videos <自己的mid> --max 20 --yaml  # 我的投稿（mid 从 whoami 拿）
```

投稿表现分析：逐个 `python3 scripts/get_video_info.py <bv_id> ...` 拿数据（走缓存），
或直接 `bili video <bv_id> --yaml`。评论反馈：`bili video <bv_id> --comments --yaml`。

## 对标分析

研究某个目标UP主（用户给了名字或链接）：

```bash
bili user "UP主名字" --yaml                  # 定位 mid + 基础数据
bili user-videos <mid> --max 20 --yaml       # 最近视频列表（标题+时长+数据）
```

分析维度：
- **更新节奏**：投稿频率、时长分布（短视频 or 长视频）
- **数据表现**：哪些视频播放/点赞显著高于均值 → 找出爆款共性（标题风格、题材、时长）
- **内容结构**：系列化（多P/合集）还是单发
- **评论区**：挑 2-3 个高表现视频 `bili video <bv_id> --comments --yaml`，看观众在夸什么、要什么

输出：对标报告——账号定位一句话、数据亮点、可借鉴的 3 个点。数据列成表格，别只给结论。

## 行为准则

- **先问深度**：用户只说"看看我账号"时，先给概况 + 问想深入哪个方向，别一上来拉全量数据。
- **批量拉取克制**：投稿列表默认 `--max 20`，视频详情逐个拿、走缓存，避免触发反爬（HTTP 412 → 减量/等待）。
- **数据说话**：分析结论必须带数字支撑（播放量、条数、占比），不凭印象。
- **对标 ≠ 抄**：给的是结构和选题模式参考，提醒用户结合自己定位。
